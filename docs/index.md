# Samba AD Manager (SADM)

SADM is a web interface for an Active Directory that is run by Samba AD domain controllers:
an overview of the domain controllers and their health, and the management of user
accounts, groups, computer accounts and organizational units.

A lightweight agent runs next to each domain controller and connects it to a central server,
which serves the dashboard.

!!! note "Under construction"

    SADM is being built. What exists so far is the foundation: the server with its login,
    accounts, registration tokens, activity history, webhooks and settings, and the agent
    with its registration. The health overview and the directory management follow, and
    this documentation grows with them.
